\chapter{Conclusion and Future Work}

This report investigated how WhatsApp could better support revocable consent for photo sharing in private conversations. The findings show that current platform controls are too limited to reflect the ongoing and changing nature of consent after a photo has been sent. In response, this report designed and evaluated \textbf{Smart Photos}, which is a prototype that treats photo sharing as an ongoing permission process. It allows permissions to be set before sending and revised afterwards. The evaluation showed that participants generally found this model supportive for user control and consent revocation when compared to existing WhatsApp features. At the same time the project also showed that consent revocation in messaging can only ever be partial. Screenshots, prior viewing and external-device capture remain structural limits that interface design cannot fully prevent. This means revocation gives meaningful control over future platform-mediated access, but does not guarantee complete erasure. The co-subject findings also suggest that photo-sharing consent can extend beyond sender and recipient to include people depicted in the image.

As discussed in Section 7.4, future work should validate these findings through live-prototype studies where the project is integrated into both web and mobile apps. This way it will be more usefull for, broader and more diverse samples, and it will help testing within real messaging infrastructure over longer-term use.
